拾图集 · 商品图片工作台 1.0.0
============================================================
一个独立编写的 Manifest V3 浏览器扩展。
用途：从当前商品页面提取图片，集中筛选、预览、下载，并记录素材来源。
运行不需要 Node.js、账号、API Key 或在线 AI。Node.js 仅用于开发测试和官网本地服务。

一、安装插件
1. 使用 extension 文件夹，或解压 releases/shituji-extension-v1.0.0.zip。
2. Chrome 打开 chrome://extensions；Edge 打开 edge://extensions。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择含 manifest.json 的 extension 文件夹。
5. 在浏览器扩展菜单固定“拾图集”图标。
6. 点击插件图标 → 打开示例商品页，可先测试图片筛选与真实下载。
安装后不要移动或删除该文件夹。

二、日常用法
打开商品网页 → 点击拾图集 → 提取当前页图片 → 筛选与勾选 → 下载。
匹配的淘宝/天猫、京东、拼多多商品页也会显示右下角“获取图片”。
在来源网页滚动，等待懒加载图片出现，再到工作台点击“补扫来源页”。
补扫只合并相同来源页面，发现原标签页跳转会阻止混合采集。

三、功能
- 提取 img/currentSrc、srcset、常见懒加载属性、picture/source、CSS 背景图及开放 Shadow DOM。
- 按完整图片 URL 去重，保留查询参数，避免破坏签名地址。
- 默认隐藏最短边不足 120px 的图，支持 400/800px 和不限尺寸。
- 按方形/横向/纵向、URL 格式和关键词组合筛选。
- 大图/紧凑布局；放大预览；键盘左右翻页，Esc 关闭。
- 全选可见、反选可见、清空选择；筛选不会丢失已选项。
- PNG 转换、可选最长边缩放；或保留原图片格式。
- 自定义文件名前缀、顺序编号、重名自动避让。
- 下载结果以浏览器完成状态为准；显示失败原因、重试失败项、停止队列。
- 导出当前可见素材 CSV，含来源页、原图地址、尺寸、采集时间。
- 最近 8 次采集本机保存，可手动清除。

四、合理边界
每次最多 400 张、DOM 扫描最多约 16000 个元素；每张最多 25MB。
PNG 转换最多 5000 万像素。动画转换为静态 PNG，不保留全部元数据。
来源不带扩展名时格式显示“未知”；原格式下载依照实际 MIME 判断。
不是图片版权授权工具。请仅使用自有或获授权素材。
不绕过登录、验证码、防盗链、跨域 iframe、封闭 Shadow DOM 或付费限制。
不自动滚动网页，不抓取商品后台接口。
真实平台的登录和页面结构经常变化，无法保证每个页面全部图片均可提取。

五、测试与证据
tests/core.test.cjs：URL、去重、srcset、筛选、文件名、CSV、商品页识别等单元测试。
tests/browser.test.cjs：实际加载扩展，检查交互、下载、转换、采集、补扫、持久化与截图。
test-results/browser-report.txt：成功运行后生成的实际检查报告。
evidence：实际浏览器运行截图；文件名区分插件、模拟商品页和官网本地预览。
商品页自动化使用本地原创 HTML 响应淘宝测试 URL，仅验证匹配和采集链路，
不代表已经在淘宝/京东/拼多多正式网站登录验收。
自动测试使用隔离浏览器资料目录，没有修改你日常浏览器的插件或数据。

七、官网预览

九、开发
npm test                       运行不依赖第三方包的 Node.js 单元测试
npm install                    安装开发测试工具 Playwright
npx playwright install chromium 安装支持扩展测试的 Chromium
npm run test:browser           浏览器集成测试
npm run assets                重建原创插画与图标
python scripts/package.py      打包插件与完整源码
可用 BROWSER_EXECUTABLE 指定兼容扩展侧载的 Chromium/Edge 测试程序。
正式 Chrome 不一定允许命令行侧载；人工“加载已解压的扩展程序”不受此测试限制影响。
自动化测试需要支持 --load-extension 的测试浏览器；不在日常浏览器资料目录运行。

十、权限与隐私
详见 docs/privacy.html。下载时按本次图片来源域名申请可选访问权限。
没有远程脚本，没有统计接口，不上传图片；不读取账号密码。
完整独立源码和原创示例插画以 LICENSE 许可提供。
